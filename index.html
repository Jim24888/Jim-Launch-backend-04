📝 功能说明与 API 规范 ▼
一、 适用范围
• 仅当广告计划的推广目标为“小游戏推广”时，才展示此配置模块。
二、 交互视图与 UI 规范
• 单账号上计划（内联模式）： 采用页面内联平铺展开的形式。选择配置项后，直接在下方动态渲染对应的表单字段，不产生额外弹窗，保证填写的流畅度。
• 多账号计划 3.0（弹窗模式）： 采用“按钮触发 + 模态框（Modal）”交互。外部表格的按钮需直观反映当前配置结果：
  - 未配置：灰底，文字 配置(未配置)
  - 选试玩且开启：蓝底，文字 配置(试玩:已开启)
  - 选试玩且关闭：灰底，文字 配置(试玩:已关闭)
  - 选直玩：蓝底，文字 配置(直玩:已配)
三、 核心业务交互逻辑
• 选择「试玩页」： 将联动显示“试玩页状态”（开启/关闭）开关。开启时展示完整的试玩页素材表单；关闭时隐藏表单内容。
• 选择「直玩页」： 隐藏状态开关（默认选中即代表使用），直接展示“直玩页引导文案”文本输入框。
四、 API 字段与校验规范
• 直玩文案限制： 对应底层接口字段 wxgame_direct_page_description。前端强制校验文本框输入为 20个字符以内。需提供实时的字数统计，超出则标红并阻断提交。
• 组件停用逻辑： 若用户对已有计划进行编辑，从“直玩页”切换回“试玩页（关闭）”或完全取消配置时，前端在组装 Payload 时需将原直玩组件对象的 is_deleted 字段传 true，以通知媒体端卸载该组件。
